# Segurança do ERP público

Este repositório contém apenas o frontend. **Nunca** faça commit de `ERP_API_KEY`, `DATABASE_URL`, backups JSON, tokens de usuário ou senhas.

O endereço pode ser público; o acesso aos dados depende de ativação local e autenticação. Para uso multiusuário em dispositivos diferentes, publique a API 1.5 e evolua gradualmente para tokens individuais com escopo de escrita.
