# Caseirinho ERP V8.4.4

- Publica os dados PIX necessários no catálogo da Loja quando houver chave PIX configurada.
- Geração de novo token continua revogando os anteriores, mas agora exibe o token completo uma única vez com botão para copiar e ativar outros navegadores.
- Mensagem antiga sobre API 1.5.0 foi removida da tela de ativação; token inválido/revogado agora orienta a usar o novo token.
- Nenhum dado operacional é apagado ao trocar token.
